# 更新日志

本文件从 0.2.0 开始记录，此前版本不做逐条追溯。

## 未发布

## v0.3.0（2026-11-26）

### feat

- API 密钥改为独立存储在用户数据目录，不再写入 `data/config.toml`；新增 `pixi run config set-key` 写入密钥，配置查看、命令行读取与日志只显示脱敏状态
- 译文弹窗字体与字号可通过 `tooltip_font_family` / `tooltip_font_size` 配置，未配置时沿用原内置字体

### fix

- 弹窗高度改为按控件实际折行数伸展，修复字号变化后估算偏小导致末行被裁的问题

### docs

- 配置参考与 README 补充密钥存储说明，配置模板移除 `api_key` 字段

## v0.2.0（2026-11-25）

### feat

- 命令行查看与修改配置（`pixi run config show / get / set`），保留原注释与排版，写入前后自动校验
- 统一终端日志格式，每轮翻译结束输出耗时与 token 统计
- 深浅主题切换：浅色为便签黄弹窗 + 白底提示框，深色为深灰配色
- 右上角提示框按等待、翻译中、出错、退出四种状态改变强调条颜色
- 弹窗加大字号与留白，边框和选中高亮从主题色推导；译文排版去掉多余空白

### fix

- 显式设置 `theme` 后，旧颜色字段仍覆盖浅色模式配色的问题

### docs

- README 精简并拆分文档到 `docs/`，补充运行截图

### chore

- 采用 MIT 许可证，版本号升至 0.2.0
